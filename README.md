# 日吉津グランルーフ midas 応力の抜き出し Excel

MGT/MGTX と ANL を選ぶだけで、計算書の節ごとに応力を確認できる Excel を作る。

- **ブラウザ版**：`index.html`（`worker.js` と `make_excel.py` を Pyodide でそのまま実行。ファイルは外へ送られない）。ローカルで開くときは `py -m http.server` で配信してから開く。GitHub Pages 公開版は下記。
- **PC版**：`start.bat` をダブルクリック → 画面でファイルを選ぶ。
- コマンドでも使える: `py -3 make_excel.py model.mgtx result.anl -o out.xlsx [--face-beam 0] [--face-col 0]`（要 openpyxl）。

作成例：`出力/日吉津_応力抽出_261021.xlsx`（案件データを含むので GitHub には載せない）（261021_構造計算書作成_最終調整 から）。

| シート | 内容 |
|---|---|
| 概要 | ファイル・単位・荷重ケース一覧。**区分（長期／短期／終局／対象外）は黄色セルで変更でき、RC シートのまとめ数式が追従する** |
| **4-1_RC柱**（チャート入力） | 柱頭・柱脚で、**チャートに入れる値（色付き）**を同じ荷重ケースの組で並べた表。長期＝NΣDL、短期・終局は「曲げ My／Mz 最大・せん断 Qy／Qz 最大・圧縮最大・引張最大」ごとに 1 ケースを選ぶ（N・My・Mz・Qy・Qz が対象、T は参考）。N は midas の符号（圧縮が負） |
| 4-1_RC柱(詳細) | 柱頭・柱中央・柱脚 × 6成分（N・Qy・Qz・T・My・Mz）を荷重ケース別に。左に長期／短期最大・最小／支配ケース／終局最大・最小（数式） |
| **4-2_RC梁**（チャート入力） | 左端・中央・右端で、チャートに入れる値（色付き）。曲げ＝My（＋最大が下端筋、−最大が上端筋）、せん断＝Qz の絶対最大。長期／短期／終局ごと |
| **4-2_RC梁(左中右)** | 部材ごとに、曲げ My・せん断 Qz を **左端／中央／右端の横並び**にした一覧（長期→短期→終局。値はチャート入力シートを参照、右にケース名）。計算書の「応力算定」と同じ並び |
| 4-2_RC梁(詳細) | RC梁（基礎梁）の左端・中央・右端の全ケース。連続する要素は 1 部材にまとめる（他の梁・支点に接しない節点でつながるもの） |
| 通り芯 | 「通り」列の判定に使った、midas の通り芯（寸法線・テキスト）の一覧 |
| 4-3_耐震壁 | 壁（板要素）の応力は ANL に無いため、板要素の一覧のみ |
| 4-4_支点まわり | 支点節点に接する要素の端部力（柱脚・接合部の検討用） |
| 断面別まとめ / グループ別まとめ | 断面ごと・midas グループごとの最大・最小と、その要素・点・ケース（トラス・つなぎ・キール・リング等の検定用） |

## 決めごと
- **通り表記**：チャートの「位置」欄と同じ書き方。部材は「BY1=BX1～BX2」（通り＝始点～終点）、通りに沿わない部材は「BX2・BY2 ～ BX3・BY2+2539」。点は「BX2・BY1」（通り上＝100 mm 以内）、離れていれば最寄りの通りからの距離を「BX2+1250」のように付ける（＋は番号が進む側＝X は東、Y は北）。通り芯は mgtx の寸法線・テキスト（`*DIMENSION`）から読む。RC部材・支点まわりは基礎レベルの BX・BY、鉄骨は屋根レベルの X・Y（部材の最低点の高さに近い寸法ビューを使う）。
- 単位は kN・kN·m に換算（ANL の単位系から自動）。値は midas の要素座標系のまま。
- 荷重ケース名は、ANL の表ごとの短縮名（NΣDL+S~4）を要約表の正式名称（NΣDL+SLU1）に直して表示。表によって「Σ」の文字コードが違うのも吸収している。
- 区分の初期値：長期＝NΣDL、短期＝SL・SLU・WZ・EX・EY、終局＝「（終局）」付き。計算書 4-1 の記載（短期は SL・SLU・WZ）と違い、EX・EY も短期に入れている。
- RC部材は断面名が「RC」で始まるもの。ほぼ鉛直なら柱、それ以外は梁。
- フェイス距離（既定 0＝節点位置）を指定すると、その距離だけ内側の値を要素の5点（I・1/4・CNT・3/4・J）から線形補間する。
- 検証：4-2 の左端・右端の値 1,584 件が、midas API で取得済みの値（33_日吉津_RC梁_midas照合/rc_forces.json）と一致。Excel で再計算してエラー無し。

## できないこと（ANL に出ていない）
板要素（耐震壁 EW40）の応力と支点反力（6-2・基礎）。midas で ANL に出力したらサンプルを見て読み込みを追加する。
